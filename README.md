# EventHub Business Platform

A simple EventHub management system with user registration, login, and data stored locally in SQLite.

## Setup

1. Install Node.js if not already installed.
2. Open a terminal in `c:\Users\HP\Desktop\Business project`.
3. Run:

```bash
npm install
```

## Run

```bash
npm start
```

Then open http://localhost:3000 in your browser.

## Features

- User registration with email/password
- Login authentication
- Local SQLite storage for user accounts
- Simple EventHub dashboard after login
